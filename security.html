TENET 02

US-Based Cloud Data Vault

All claim repositories, inspection photographs, and carrier communications are hosted in domestic US data centers on Amazon Web Services (AWS us-east-1). Data is encrypted at rest via AES-256 and in transit via TLS. AWS data facilities maintain SOC 2 Type II compliance.

  • AES-256 Encryption at Rest: All files and database storage are encrypted at rest using AES-256 via AWS Key Management Service (KMS).
  • TLS 1.3 in Transit: Perfect forward secrecy prevents interception across mobile and office networks.
  • Geographically Redundant: Continuous data backups to a secondary AWS facility for rapid disaster recovery.
US-only data sovereignty Zero offshore routing

TENET 04

Strict Multi-Tenant Isolation

Every public adjusting firm operates within an isolated tenant partition with strict authorization gates, ensuring an adjuster at Firm A cannot access files from Firm B.

  • Granular Staff Roles: Limit access between senior PAs, field apprentices, estimators, and admin staff.
  • Expiring Guest Tokens: Outside structural engineers and forensic CPAs only access specific approved line items.
  • Immutable Audit Logs: Every access timestamp is recorded to prove chain-of-custody in appraisal or court.
